📌𝗗𝗮𝘆 𝟯-𝗟𝗲𝗮𝗿𝗻𝗶𝗻𝗴 𝗟𝗶𝗻𝘂𝘅 𝗳𝗼𝗿 𝗖𝗹𝗼𝘂𝗱 - Hands-On with Basic Linux Commands.
Today was all about strengthening the foundation — understanding the essential Linux commands that let you see, monitor, and navigate your system.
Here’s what I explored, step-by-step:
𝟭. 𝗽𝘄𝗱 — 𝗣𝗿𝗶𝗻𝘁 𝗪𝗼𝗿𝗸𝗶𝗻𝗴 𝗗𝗶𝗿𝗲𝗰𝘁𝗼𝗿𝘆
This command tells you exactly where you are in the filesystem.
 Think of it as asking Linux: “What’s my current location?”
🔹 Useful when navigating deep directories or verifying your current working path.
𝟮. 𝗹𝘀 & 𝗹𝘀 -𝗹 — 𝗟𝗶𝘀𝘁𝗶𝗻𝗴 𝗙𝗶𝗹𝗲𝘀 𝗮𝗻𝗱 𝗗𝗶𝗿𝗲𝗰𝘁𝗼𝗿𝗶𝗲𝘀
ls shows all files and folders in your current directory.
 ls -l goes deeper — it shows file permissions, ownership, size, and modification dates.
🔹 Helps you understand who owns what and what kind of access each file has — critical for cloud and server management.
𝟯. / — 𝗧𝗵𝗲 𝗥𝗼𝗼𝘁 𝗗𝗶𝗿𝗲𝗰𝘁𝗼𝗿𝘆
This is the starting point of the entire Linux filesystem hierarchy.
 Every file, folder, and device starts here.
🔹 Understanding / is key to knowing how Linux organizes everything — from user data to system binaries.
𝟰. 𝗱𝗳 -𝗵 — 𝗗𝗶𝘀𝗸 𝗦𝗽𝗮𝗰𝗲 𝗨𝘀𝗮𝗴𝗲
This command shows how much disk space is used and available, in human-readable format (GB/MB).
🔹 In cloud environments, you’ll constantly monitor this to avoid storage issues or plan scaling.
𝟱. 𝗳𝗿𝗲𝗲 -𝗵 — 𝗠𝗲𝗺𝗼𝗿𝘆 𝗨𝘀𝗮𝗴𝗲
Shows how much RAM is free, used, or cached.
🔹 Critical for diagnosing performance problems and ensuring efficient instance utilisation in AWS or any cloud setup.
𝟲. 𝘁𝗼𝗽 — 𝗥𝗲𝗮𝗹-𝗧𝗶𝗺𝗲 𝗦𝘆𝘀𝘁𝗲𝗺 𝗠𝗼𝗻𝗶𝘁𝗼𝗿𝗶𝗻𝗴
Displays running processes, CPU usage, memory usage, and more — updated live.
🔹 Think of it as Linux’s built-in performance dashboard — the CLI version of Task Manager.
